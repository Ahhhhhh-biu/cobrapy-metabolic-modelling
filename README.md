# COBRApy Metabolic Modelling

Constraint-based metabolic analysis with FBA, pFBA, flux variability analysis, medium perturbations and gene deletions.

## Installation and use

Tested with Python 3.12 and the GLPK solver.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python metabolic.py --out results/core_run
python metabolic.py --sbml path/to/model.xml --out results/custom_run
```

Use a new output directory for every run. The default input is the published E. coli core reference reconstruction loaded through COBRApy: 95 reactions, 72 metabolites and 137 genes. The SBML option is a loading interface; exchange IDs, objective, medium and interpretation must be adapted for another reconstruction.

## Analyses

- FBA optimisation using the model objective.
- pFBA with verification that the original growth objective is retained.
- FVA at 95% of the optimal objective for selected reactions.
- A 3 by 3 glucose/oxygen uptake-cap sweep.
- Five gene deletions with explicit handling of infeasible solutions.
- Steady-state, flux-bound, monotonicity and model-restoration checks.

## Recorded reference results

Files prefixed `example_` contain outputs from the core reference reconstruction. Baseline predicted growth is approximately 0.873921507 under the saved default medium; maximum steady-state residual is approximately 1.42e-13 and maximum bound violation is zero. These values describe model simulations under the recorded assumptions.

`example_results.json` records model scope, medium, objective, package versions, solver settings and the generated snapshot hash. The snapshot itself is generated by the script rather than redistributed here. The glucose/oxygen sweep is a separate protocol from the baseline medium.

## Interpretation

The model is a core teaching reconstruction rather than a genome-scale or human metabolic network. FVA describes feasible flux ranges, not statistical confidence intervals. Growth and deletion predictions depend on medium, objective, reconstruction and gene–reaction rules. Biological interpretation requires observations matched to organism and conditions.

The numerical tolerance of 1e-7 is an engineering check. Infeasible cases are recorded as such rather than assigned invented experimental values. No private data are included.
